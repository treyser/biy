# Бій — розширення для Owlbear Rodeo

Порядок ходу: ініціатива героїв і ворогів, підсвітка того, хто ходить зараз.

## Як користуватись

1. **ПКМ на токені → «Бій»**. У панелі обери, чий це лист персонажа,
   або лиши «Ворог (без листа)». Натисни «Додати в бій».
2. Іконка «Бій» угорі зліва відкриває вікно з порядком ходу.
3. Майстер тисне **«Почати бій»** — ворогам ініціатива кидається одразу,
   героям зʼявляється кнопка **«Кинути ініціативу»** в їхньому вікні.
4. **«Наступний»** передає хід далі, після останнього починається новий раунд.
5. Клік по рядку наводить камеру на токен.

6. Клік по рядку (майстру — будь-якому, гравцю — свого героя) розгортає
   редактор: **як виглядає** учасник (неушкоджений → ледве живий, без цифр ХП;
   для героя — «Непритомний», для всіх — «Мертвий»), **стани** з правил 5e з
   кількістю раундів (сам зникають на початку нового раунду; порожньо — доки не
   знімеш), бонус до ініціативи, перекидання, вилучення з бою.
7. Мертві пропускаються в черзі; непритомний герой свій хід зберігає (рятівні кидки).

**Смуга вгорі** — як у Baldur's Gate 3: той, хто ходить, першим і більшим, у
золотій рамці; далі черга, розділювач «Раунд N», після нього ті, хто вже
походив. Під портретом — п'ять поділок здоров'я, у куточку — значки станів.
Гравець, чий зараз хід, бачить банер «Ваш хід!».

**Кидок ініціативи.** Щойно майстер починає бій, у гравця відкривається вікно
з d20: «Кинути d20» або вписати свій кидок фізичним кубиком, плюс додатковий
бонус. Спритність береться з листа персонажа.

**Зв'язок з «Атмосферою»** (галочка в майстра): початок бою показує всім титр
«До бою!» і вмикає бойову музику (або музику боса — галочка «Бій з босом»),
кінець бою повертає попередню музику й записує підсумок у корабельний журнал.

Ініціатива — d20 плюс модифікатор Спритності з привʼязаного листа.
При рівних значеннях вище стає той, у кого більша Спритність.

## Як влаштовано

| Файл                | Що робить                                               |
| ------------------- | -------------------------------------------------------- |
| `src/background.js` | Реєструє пункт контекстного меню.                        |
| `src/menu.js`       | Привʼязка токена до листа, додавання й вилучення з бою.  |
| `src/main.js`       | Вікно з порядком ходу, кидки, перемикання ходів.         |
| `src/state.js`      | Читання й запис стану, сортування, кубик.                |

Стан бою лежить у метаданих кімнати, привʼязка токена до листа —
у метаданих самого токена.

Розширення читає листи персонажів із метаданих кімнати за ключем
`com.nikita.character-sheet/sheets`, тож потребує встановленого
розширення «Лист персонажа». Гравець упізнається за кодом
`sheet-owner` у localStorage — обидва розширення на одному домені,
тому код спільний.

## Публікація

Репозиторій має називатися `biy` — назва зашита в `vite.config.js`
та в адресах у `public/manifest.json`.

1. Settings → Pages → Source: **GitHub Actions**
2. `git push`

Встановлення: профіль → Add Extension → `https://treyser.github.io/biy/manifest.json`
